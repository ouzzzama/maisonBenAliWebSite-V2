A statically-served marketing site for an Agadir real-estate group, with one
small Express backend for lead intake. It is NOT a SPA and NOT a framework app:
every page is hand-written HTML with global CSS/JS, plus a Node server that
serves the files, enforces clean URLs and exposes a single JSON API.

6. BACKEND — server.js
--------------------------------------------------------------------------------

Port
  process.env.PORT || 3001; started via npm start / npm run dev
  (both run: node server.js)

Clean URLs
  Any /x.html -> 301 to /x ; /index.html -> 301 to /
  Static serving: express.static(__dirname, { extensions: ["html"],
  dotfiles: "ignore" }) — so /a-propos resolves a-propos.html

Hardening
  BLOCKED_PATH regex 404s dotfiles (.env), server.js, package*.json and
  node_modules/* before static serving.
  Static assets are otherwise public.

POST /api/reservation  (lead intake: property visits + Benali Cars rentals)
  - JSON body limit 32 KB
  - every field passed through clean(): control characters stripped,
    whitespace trimmed, per-field max length
  - rejects phone numbers with fewer than 6 digits -> 400
  - stored record fields: id (base-36 timestamp), receivedAt, type, property,
    name, phone, email, date, car, from, to, message, page
  - appends one JSON line to data/reservations.jsonl (folder created on demand)
  - responds 201 {ok:true,id} or 500 {ok:false,error}
  - no database, no authentication, no rate limiting — append-only file storage

Catch-all
  app.get("*") returns index.html, so unknown paths land on the home page.

Deployment / hosting
